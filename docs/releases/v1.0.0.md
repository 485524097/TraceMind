# TraceMind v1.0.0

TraceMind v1.0.0 是第一个完整的日常使用版本：一个本地优先、答案可追溯、面向长期学习与技术积累的个人 AI 知识库。

## Highlights

- **Local-first personal knowledge base**：文档、结构化数据、向量索引和 Knowledge snapshot 默认保留在本机。
- **Document processing**：支持普通多文件上传、PDF、DOCX、Markdown、TXT 与通用技术代码文件，展示 Upload、Parse、Index 和 Ready 状态。
- **Hybrid Retrieval**：Qwen3 Embedding、Dense、Qdrant BM25、RRF、可选 Cross-Encoder Reranker、Query Rewrite 与 Path Scope。
- **Traceable Streaming RAG**：确定性 Direct / RAG routing、SSE Streaming、Pipeline Trace、Citation Guard 和 Evidence Inspector。
- **Conversation**：保存用户问题、assistant answer、来源和终态，并支持取消与错误恢复。
- **KnowledgeEntry**：将重要回答沉淀为 Question、Background、Root Cause、Solution、Failed Attempts、Tags、validation status 与安全 Evidence snapshot。
- **Knowledge Map**：从 PostgreSQL 实时派生 Knowledge Base、Document、KnowledgeEntry 和 Tag 的可解释关系图。
- **Retrieval Evaluation**：固定 corpus、24-case dataset、固定 baseline 与 isolated Qdrant regression gate。

## Architecture Decisions

- 代码文件与其他技术资料走同一条通用 Parse、Chunk、Index 与 Retrieval 路径；v1.0 删除了 Java Symbol-aware Retrieval 和目录级代码仓库导入，降低维护面并聚焦个人学习闭环。
- Direct / RAG Router 使用确定性完整字符串规则，仅简单寒暄走 Direct；知识问题和不确定输入进入 RAG，不依赖 LLM 做路由判断。
- KnowledgeEntry 保存安全 allowlist snapshot。Conversation 或 Document 删除后仍可查看历史证据快照。
- Knowledge Map 直接从 PostgreSQL、KnowledgeEntry tags 与 live cited Document 派生，不增加 Graph DB、graph persistence 或 GraphRAG。
- Retrieval、RAG 和 Knowledge Map 保持职责分离；Knowledge Map 不参与检索或回答生成。

## Known Limitations

- 远程 OpenAI-compatible LLM 的 TTFT 与总耗时可能出现长尾；敏感资料需要使用本地 provider 或先完成脱敏。
- 在 CPU-only 环境中，Cross-Encoder Reranker 是主要的稳定本地 RAG latency 来源。
- Knowledge Map 面向个人数据规模，当前不提供大图分页、聚类、缓存或图检索。
- Embedding 和 Reranker 首次下载或首次加载存在明显等待；离线运行需预先准备模型缓存。
- PDF 只处理可提取文本层，暂不提供 OCR。

## Upgrade Notes

- 从较早开发版本升级时执行 `uv run alembic upgrade head`。
- v1.0 删除旧 Java Symbol payload；已有本地 Qdrant collection 应按当前文档重新建立索引。
- 不要提交 `.env`、API key、模型凭据或本地上传资料。
