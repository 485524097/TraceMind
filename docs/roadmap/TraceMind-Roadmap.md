# TraceMind Roadmap

## Current

Stage 15 — v1.0 Architecture Reset & Daily-Use Readiness。

目标是删除 Java-specific Retrieval，完成通用个人学习 RAG、性能测量、过程反馈、中文化
与真实日常使用验收。

## After v1

进入 Learning & Experiment Phase，不再规划新的 Feature Stage。后续工作仅由真实使用证据
驱动：

- 深入理解源码与面试准备
- Bug fix
- 固定 Benchmark
- Retrieval Experiment
- 真实使用反馈

任何新功能必须先说明当前问题、可测成功标准和最小维护成本。
