# 技术选型记录

## 现有基线

| 领域 | 当前选择 | 主要理由 |
| --- | --- | --- |
| API | FastAPI + Pydantic v2 | 异步 Python API、类型校验与自动接口文档。 |
| 数据库 | PostgreSQL + SQLAlchemy 2 + Alembic | 关系元数据、事务约束和可演进 schema。 |
| 异步任务 | Redis + Celery | 文档解析可脱离 HTTP 请求执行并支持重试。 |
| 向量库 | Qdrant | 为后续 Chunk 向量索引和过滤检索预留。 |
| 前端 | Vue 3 + TypeScript + Vite + Element Plus | 快速构建中文管理端并保持类型约束。 |
| 部署 | Docker Compose | 满足 MVP 本地优先、一键启动的需求。 |

## 新选型模板

### <组件或服务>

- **需求**：需要解决的具体问题及约束。
- **候选方案**：至少列出当前方案与可行替代方案。
- **选择**：最终选择及依据。
- **不选理由**：为何不采用其他方案。
- **影响**：性能、成本、隐私、许可证、运维、迁移和锁定风险。
- **验证**：PoC、压测、兼容性测试或评测结论。
- **复查条件**：在何种规模、成本或能力变化下重新评估。
