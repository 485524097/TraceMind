# Agent 设计

## MVP 原则

MVP 优先使用确定性的检索与问答工作流。仅当问题需要多步工具选择、计划或验证时，才增加受限 Agent。

## Agent 边界

- 只能通过登记的工具读取知识库、检索、生成或执行明确授权的操作。
- 不得绕过检索引用链路，不得自行捏造来源。
- 默认只读；任何写入、删除、外部调用或批量操作必须由用户明确授权。
- 每次调用需记录工具名、输入摘要、输出摘要、耗时、失败原因、模型配置和使用的引用；日志不得保存敏感原文。

## 设计记录模板

- **用户价值**：为何确定性流程无法满足。
- **流程**：输入、计划、工具调用、终止条件与输出。
- **工具契约**：参数、返回、权限、超时、重试、幂等性和错误语义。
- **安全与成本**：数据边界、提示词注入防护、调用上限和降级策略。
- **评测**：任务成功率、引用正确性、工具误用率、延迟和单位任务成本。
